# Privacy Policy

Last updated: 2026-11-01

This OAuth client ("the app") is a personal configuration of
[rclone](https://rclone.org/), an open-source command-line program, operated by
a single individual for their own use.

## What the app does

The app lets rclone, running on the operator's own computers, read and write
files in the operator's own Google Drive account.

## Data collected

The app collects no data about anyone other than the operator. It has no
server. The only data it handles are:

- an OAuth access token and refresh token, stored in the rclone configuration
  file on the operator's computer;
- file contents and metadata of the operator's own Google Drive, which are
  transferred directly between Google's servers and the operator's computer.

## Data sharing

No data is shared with, sold to, or made available to any third party. Nothing
is sent anywhere other than Google's APIs and the operator's own machines.

## Data retention and deletion

Tokens can be revoked at any time from
<https://myaccount.google.com/permissions>. Deleting the rclone configuration
file removes all stored credentials.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
